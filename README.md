## Снижение размерности: метод главных компонент

Занятие курса «Искусственный интеллект» для 9 класса. Ученики на опыте видят проклятие размерности и пишут на чистом Python метод главных компонент: центрирование, ковариационная матрица, степенной метод, исчерпывание, проекция и восстановление. Затем они переносят набор Wine из 13 признаков на плоскость, честно сравнивают метод k ближайших соседей до и после снижения размерности через кросс-валидацию и выясняют, в каких данных метод главных компонент не помогает.

## Теория (презентация)

1. **Проклятие размерности.** В пространстве большой размерности расстояния выравниваются: ближайшая точка почти так же далека, как самая далекая. Почти весь объем многомерного куба лежит у его границ. Лишние случайные признаки ломают метод k ближайших соседей.
2. **Дисперсия и ковариация.** Центрирование, дисперсия признака, ковариация двух признаков, ковариационная матрица облака точек лидара на кузове машины.
3. **Главные компоненты.** Направление наибольшей дисперсии и ориентация машины по облаку точек. Проекция, собственные векторы ковариационной матрицы, степенной метод, исчерпывание для следующих компонент, доля объясненной дисперсии и выбор числа компонент. Набор Wine на плоскости, влияние стандартизации, чтение весов компоненты, восстановление данных и его ошибка. Обучение метода только на обучающей выборке, метод k ближайших соседей после снижения размерности, ограничения метода. Рукописные цифры 8 × 8.
4. **Практика.** План из восьми заданий.

## Практическая работа

| Задание | Что пишем | Главный результат |
| --- | --- | --- |
| П1 | `near_far_ratio`, `shell_share`, `add_random_features` | в пространстве большой размерности все точки почти одинаково далеко |
| П2 | `mean_vector`, `center`, `covariance` | ковариационная матрица облака точек машины |
| П3 | `matvec`, `norm`, `power_iteration` | первая компонента показывает, куда повернута машина |
| П4 | `deflate`, `pca_fit`, `pca_transform` | вторая компонента и доля объясненной дисперсии |
| П5 | набор Wine на плоскости | две компоненты из 13 хранят 55 % дисперсии, сорта видны на рисунке |
| П6 | `pca_inverse`, `reconstruction_error` | ошибка восстановления равна сумме отброшенных дисперсий |
| П7 | `knn_pca_model` в кросс-валидации | 2 признака вместо 13 почти без потери точности |
| П8 | `add_noisy_copies`, `knn_after_pca` | при шумовых признаках компоненты находят шум, а не полезную информацию |

Задания повышенной сложности: метод главных компонент на рукописных цифрах 8 × 8 и восстановление изображений, повернутые прямоугольники вокруг объектов на парковке, скорость сходимости степенного метода, кластеризация после снижения размерности, метод k ближайших соседей на цифрах до и после снижения размерности.
